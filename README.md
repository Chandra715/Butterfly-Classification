# 🦋 Butterfly Classification using ML & Deep Learning

## Overview
Hybrid ML pipeline for butterfly classification using MobileNet feature extraction + Fuzzy KNN and XGBoost.

## Features
- Transfer learning (MobileNet)
- Custom Fuzzy KNN
- XGBoost comparison
- Image preprocessing

## Tech Stack
Python, TensorFlow, OpenCV, Scikit-learn, XGBoost

## Run
pip install -r requirements.txt
python src/train.py
